What's in the game

No shops. No fluff. Just tennis.

🎯

Timing System

A glowing ring appears near the ball. Hit at the perfect moment for a power shot — too early or late and the ball goes weak or out.

⚡

Shot Types

Flat, Topspin, Slice, Lob, Smash, and Serve — each with unique arc physics, bounce behavior, and spin effects.

✨

Neon Graphics

Bloom, SunRays, Atmosphere post-processing. Neon ball trail, bounce sparks, glowing court edge trim, and a crisp blue hard court.

🏆

Full Match Scoring

Real tennis scoring — Points, Games, Sets, Deuce, and Advantage. Best of 3 sets to win the match.

👥

2-Player Multiplayer

One player per side of the net. Server-authoritative hit validation so no cheating the timing window.

📱

Mobile + PC

Tap to hit on mobile, click or Space on PC. Sprint with Shift. Works on all devices Roblox supports.

⚡ Deuce Rule

When both players reach 40 — it's DEUCE.

Win the next point → ADVANTAGE.
Win again → GAME.
Lose advantage → back to DEUCE.

Get it in Roblox Studio

Using Rojo (recommended) or manual copy-paste.

1

Clone the repo

git clone https://github.com/Rishik-Sundar/spike-tennis

2

Start the Rojo dev server

Run rojo serve inside the project folder. Install Rojo v7+ if you don't have it.

3

Connect in Studio

Open Roblox Studio → click the Rojo plugin → Connect. All scripts sync instantly.

4

Hit Play and test

Open a local server with 2 player slots to test multiplayer. Both players load into opposite sides of the court automatically.
